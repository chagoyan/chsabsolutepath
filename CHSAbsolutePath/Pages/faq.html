FAQ

Why does my page need the whole https:// address?

Your page lives on your computer. These files live on the internet. A short path like Images/cat.png makes the browser look for a folder on your computer.

Do I type CHSAbsolutePath in the address?

No. https://chsabsolutepath.netlify.app/ already stands for that folder. Start with the folders inside it.

My image shows a broken icon. Now what?

Copy the address out of your src and paste it into the browser's address bar. If the file doesn't open there, the address is wrong. Check the site map again.

Do capital letters matter?

Yes. Type every folder and file name exactly as the site map shows it.

Do I need the file extension?

Yes. cat and cat.png are different names. Always end with the extension.
